# CAPITÃO Design System 1.0

## Direção

Soft 3D Civic UI: superfície clara, cards grandes e arredondados, sombra suave, cores pastel por ecossistema e feedback tátil.

## Cores-base

- Primary 900: `#083D29`
- Primary 700: `#0B5135`
- Primary 500: `#297A56`
- Primary 100: `#DCEDE3`
- Background: `#F7F8F5`
- Surface: `#FFFFFF`
- Text: `#151817`
- Text secondary: `#646A67`
